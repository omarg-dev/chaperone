# Changelog

What each release brought, for the people who use it. A release is a `dev → prod` merge and
bumps the patch version.

## 0.1.1

- The arena has 22 benign shopping requests (precise, vague, brand named or ruled out, "wired is fine", two of something, tight and loose budgets) across keyboards, headphones and mice, so the false block rate rests on more than easy cases.
- An eval run writes its first off-vs-on numbers: attack success, false blocks, false escalations, cost and latency with the firewall off, Gate 0 only and the full review tree, in one results file and summary.
- The mandate builder's reading of every new request is recorded, and a scenario can say which brands the person wanted or ruled out.
